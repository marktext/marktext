guide.md

Руководство

Проект использует строгий режим TypeScript и ESLint. Сборка описана ниже, проверка типов не отключается.

Сборка

Команды запускаются из корня репозитория, потому что lockfile и workspace-скрипты лежат только там, а не в пакете desktop.

Корень ставит зависимости один раз. Пакеты desktop, muya и website берут их из общего lockfile и не держат своих копий.

После установки postinstall патчит native-keymap, скачивает Electron и собирает нативные модули. Минификация локалей нужна только production-сборке.

Проверка

Тесты лежат в каталоге test/unit и запускаются командой pnpm test. Отдельный прогон одного файла идёт через vitest из пакета desktop.

Линтер и проверка типов обязательны перед коммитом. CI гоняет их на каждой сборке pull request и не мержит красную ветку.

Сквозные сценарии лежат в Playwright. Конфиг остаётся в пакете desktop, потому что Playwright читает его из каталога запуска.

Упаковка

Установщики собирает electron-builder: AppImage, deb и rpm. Готовые файлы попадают в dist корня, туда же смотрит CI.

Иконки и скрипты NSIS лежат в build пакета desktop. Локали перед упаковкой минифицируются, в dev-запуске этот шаг пропускается.

Смена версии Electron требует пересборки нативных модулей. Без этого окно не поднимается: keymap и проверка орфографии собраны под прошлый ABI.
