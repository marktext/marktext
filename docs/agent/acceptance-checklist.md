## Что запускает редактор

Harness выбирается на странице **Настройки → Агент**. Модель репозитория выбирается в шапке чата. На странице «Агент» список моделей только для чтения. Пустой путь — поиск команды в `PATH`.

| Harness  | Команда по умолчанию | `repliesVia` | Как ответ попадает в тред                         |
| -------- | -------------------- | ------------ | ------------------------------------------------- |
| OpenCode | `opencode acp`       | `mcp`        | вызов инструмента `marktext.reply_to_thread`      |
| Pi       | `pi-acp`             | `block`      | последний блок `marktext-replies` в тексте ответа |
| Cursor   | `agent acp`          | `block`      | последний блок `marktext-replies` в тексте ответа |

Значения Pi и Cursor — текущая настройка адаптера. Прогон строки «Запасной путь» как раз проверяет, что ответ треда пришёл из блока. Если у Pi или Cursor в ходе виден вызов `marktext.reply_to_thread`, а блока нет, это расхождение: ответ не должен зависеть от инструмента, которого адаптер не ждёт.

Ключи провайдеров в MarkText не вводятся. Их настраивают в самом harness.

## Подготовка

Один раз на ОС, затем та же папка для всех установленных harness.

1. `git init` во временной папке, `git config user.name` и `user.email` заданы локально. Имя из `user.name` станет подписью реплик.
2. Файл `guide.md` в корне, в нём абзац со словом `strict` и второй абзац `Beta paragraph`. Рядом `notes.md` с фразой `foreign quote`. Коммит `init`.
3. Окно шире 1500 px, чтобы панель агента была не полосой.
4. **Настройки → Агент**: «Агентский режим» включён. Для каждой установленной программы путь пуст или указывает на бинарь, «Проверить» показывает «Найден». Если моделей нет, их добавляют в harness и нажимают «Обновить».
5. Запишите в журнал версию каждой программы и имя модели, которой идёт прогон.

Сценарии 1, 8, 9 и 10 не требуют ответа модели. Если harness не установлен, в его колонках стоит `—`, а сам сценарий всё равно выполняется один раз на ОС при любом включённом режиме. Сценарии 2–7 и запасной путь для отсутствующей программы не выполняются.
