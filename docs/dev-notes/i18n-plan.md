# i18n 国际化方案

## 当前状态
- 项目中**没有任何 i18n 基础设施**
- ~463 个硬编码英文字符串分散在主进程（菜单）和渲染进程（Vue 组件、偏好设置、命令描述等）
- 已有一个 `language` 偏好字段（默认 `en`），但在 UI 中被**禁用**，只有一个选项

## 技术选型
- **库**: `vue-i18n@8`（Vue 2.x 兼容版本）
- **切换方式**: 动态切换（无需重启）
- **初始语言**: 英文 (en-US) + 简体中文 (zh-CN)
- **Element UI**: 与应用语言同步切换

## 架构设计

```
src/
├── renderer/
│   ├── i18n/
│   │   ├── index.js              # i18n 初始化 + Element UI 同步
│   │   └── locales/
│   │       ├── en-US.json        # 英文（基准，完整）
│   │       └── zh-CN.json        # 简体中文
│   └── main.js                   # 注册 VueI18n 到 Vue
├── main/
│   ├── i18n.js                   # 主进程简易翻译函数 (setLocale / t)
│   └── menu/                     # 菜单模板全部重构为接受 t() 参数
```

## 核心流程
1. 渲染进程用 `vue-i18n` 驱动所有 Vue 组件，`$t('key')` 响应式切换
2. 语言切换时，通过 IPC 将翻译数据发送给主进程
3. 主进程收到后重建所有窗口菜单
4. Element UI 的 `locale.use()` 同步切换

## 实施步骤

### 阶段一：基础框架
- 安装 `vue-i18n@8`
- 创建 `en-US.json` 和 `zh-CN.json` 翻译文件
- 创建 `src/renderer/i18n/index.js` 初始化
- 在 `src/renderer/main.js` 中集成

### 阶段二：主进程菜单翻译
- 创建 `src/main/i18n.js` 简易翻译模块
- 在 `src/main/menu/index.js` 中添加 IPC 监听
- 修改 10 个菜单模板文件，将硬编码字符串替换为 `t('key')` 调用
- 语言切换时触发菜单重建

### 阶段三：渲染进程字符串替换
- Vue 模板：`"Hardcoded"` → `$t('key')`
- 命令描述：重构 `descriptions.js` 从硬编码映射改为 `i18n.t()` 调用
- 偏好设置配置：下拉选项 label 改为翻译键
- 主进程编辑器右键菜单：接受 `t()` 函数

### 阶段四：语言切换 UI
- 启用偏好设置中的语言下拉框（去掉 `:disable="true"`）
- 填充 `languageOptions` 为 `['en-US', 'zh-CN']`
- 在 Vuex store 中监听语言变化，触发 IPC 通知主进程
- 应用启动时读取已保存的语言偏好并加载
